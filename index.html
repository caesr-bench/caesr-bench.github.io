Motivation

Four capabilities, each tested on its own.

An executable scene replica is useful when it matches the target scene, responds to new inputs the way the target does, supports planning and control, and can be updated when the target changes. CAESR-Bench tests these four capabilities separately. Each category supplies what the earlier stages would have produced, so its score reflects only the part the agent builds.
